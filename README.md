# 化學式組合遊戲

給國中理化課使用的觸控大螢幕小遊戲。學生從元素週期表依化學式順序點選元素，組出常見物質；含括號的原子團會變成特殊按鈕，組合成功後物質卡飛進下方格子，湊滿 10 格即過關。

- 單一檔案 `index.html`，不需要安裝、不需要網路連線（發佈後也只要開網頁）。
- 週期表：118 個元素，含原子序、元素符號、中文名稱、注音、原子量（整數），顏色依中國化學會週期表分類。
- 老師模式：可新增、編輯、刪除題目，設定出題範圍與題數（預設 10 題，其中 4 題進階）。

## 發佈到 GitHub Pages

1. 建立新的 repository（可設為 Public）。
2. 把本資料夾的檔案上傳到 repository 根目錄（`index.html` 一定要放在最外層）。
3. 到 **Settings → Pages**，Source 選 **Deploy from a branch**，Branch 選 `main`、資料夾選 `/ (root)`，按 Save。
4. 約 1 分鐘後，網址會是 `https://<帳號>.github.io/<repository 名稱>/`。

也可以直接下載 `index.html`，用瀏覽器開啟使用。

## 老師模式與匯入題目

1. 點右上角淡淡的 ⚙，輸入密碼進入老師模式。
2. **匯出題庫（Excel）**：下載 `化學式題庫.xlsx`，可直接用 Excel 編輯。
3. **匯入題庫（Excel／CSV）**：選擇 `.xlsx` 或 `.csv`，可選擇「取代」或「加到現有題庫後面」。
4. 本資料夾的 `題庫範本.xlsx` 是預設的 24 題，可以當作範本修改。

Excel 欄位（第一列是標題）：

| 中文名稱 | 化學式 | 難易（易/難） | 提示 | 說明 |
|---|---|---|---|---|
| 硫酸鋁 | Al2(SO4)3 | 難 | 鋁離子＋硫酸根 | 淨水劑，可使水中雜質沉澱 |

- 化學式用一般數字書寫（例如 `H2SO4`、`Ca(OH)2`），程式會自動轉成下標。
- 需要括號的原子團（兩個以上）才寫括號，如 `Ca(OH)2`；只有一個原子團時不寫括號，如 `NaOH`。
- 提示、說明可以空白。
- 化學式有誤的列會被略過，並在匯入時提醒。
- 化學式裡新的原子團會自動加入原子團清單。

## 注意事項

- 題庫存在每一台電腦、每一個瀏覽器自己的儲存空間（localStorage）。換電腦或清除瀏覽器資料就會消失，請定期匯出 Excel 備份，需要時再匯入。
- 老師模式的密碼寫在 `index.html` 的程式裡（搜尋 `老師模式` 附近的 `pw').value==`），只用來避免學生誤觸，**不是安全機制**。公開 repository 的人都看得到，請自行修改後再發佈。
- 中文使用標楷體（DFKai-SB／BiauKai），英文數字使用 Arial；系統沒有這些字型時會自動換成其他字型。
- 音效由瀏覽器即時產生，需要先點過畫面才會發聲，右上角 🔊 可靜音。
