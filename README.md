# 化學式組合遊戲

給國中理化課使用的觸控大螢幕小遊戲，有三種玩法：

- **⚗️ 組合分子**：從元素週期表依化學式順序點元素，組出常見物質；含括號的原子團會變成特殊按鈕，組合成功後物質卡飛進下方格子，湊滿格子即過關。
- **🔬 元素認識**：點選任一元素，出現全螢幕介紹（簡介、生活用途、小知識、圖片、常見物質）。
- **🎯 元素挑戰**：畫面顯示兩段線索（從簡介、生活用途、小知識隨機抽兩項，已遮住元素名稱），學生點週期表上的元素作答；答對的效果同組合分子，湊滿格子過關。

單一檔案 `index.html`，不需要安裝。週期表有 118 個元素（原子序、符號、中文、注音、整數原子量）。

## 資料夾內容

| 檔案 | 用途 |
|---|---|
| `index.html` | 遊戲本體（首頁，檔名不要改） |
| `題庫.xlsx` | 題庫：中文名稱、化學式、難易（易/難）、提示、說明 |
| `元素介紹.xlsx` | 元素介紹：118 個元素各一列，已填好 40 個；最後一欄「圖片檔名」 |
| `config.json` | 設定檔：把排行榜網址填在 `gas` 欄位（不用排行榜就留空） |
| `GAS程式碼.gs` | 排行榜的後端程式，貼到 Google Apps Script（不需要上傳到 GitHub 也可以） |
| `images/` | 元素圖片，檔名填在 `元素介紹.xlsx` 的「圖片檔名」欄 |

## 發佈到 GitHub Pages

1. 建立 repository，把本資料夾的檔案與資料夾上傳到**最外層**。
2. **Settings → Pages**：Source 選 *Deploy from a branch*，Branch 選 `main`、資料夾選 `/ (root)`，Save。
3. 約 1 分鐘後，用 `https://<帳號>.github.io/<repository 名稱>/` 開啟。

## 怎麼更新題庫與元素介紹（大家都會看到最新的）

網頁每次開啟，都會自動讀取同一層的 `題庫.xlsx` 與 `元素介紹.xlsx`，**以 GitHub 上的檔案為準**。

1. 在電腦上用 Excel 修改 `題庫.xlsx`（或 `元素介紹.xlsx`），存檔（檔名不要改）。
2. 到 GitHub repository 頁面，**Add file → Upload files**，把檔案拖進去覆蓋，按 Commit。
3. 約 1～10 分鐘後，大家重新整理（Ctrl+F5）就會看到最新內容。

圖片：把圖片放進 `images/` 資料夾，並在 `元素介紹.xlsx` 的「圖片檔名」欄填檔名，多張用分號分隔，例如 `O-1.jpg;O-2.jpg`。建議用自己拍攝或可自由使用的圖片，每張小於 300 KB。

Excel 小提醒：
- 化學式用一般數字，如 `Al2(SO4)3`、`Ca(OH)2`；兩個以上相同原子團才加括號，只有一個原子團不加括號（`NaOH`）。
- 化學式有誤的列會被略過；沒有填內容的元素列不會影響內建介紹。
- 老師模式的「匯出題庫（Excel）」「匯出元素介紹（Excel）」可以把目前內容匯出，修改後再放回 GitHub。

## 計時與排行榜（Google 試算表 + Apps Script）

**玩法規則**
- 每一局開始時，畫面只顯示一個大的「▶ 開始」按鈕；按下後**題目才會出現，同時開始計時**。
- 右下角有計時碼表（小數一位），**不含動畫時間**；開啟說明、排行榜等視窗、切換到其他分頁時也會暫停。
- 登錄暱稱後，每次「過關」（滿 10 格，題數可在老師模式調整）就會上傳成績，並顯示自己的名次。
- 排行榜分三種：**總榜**、**化學式**、**認識元素**，每一種都顯示「累積時間／挑戰次數」。
  - 總榜排序＝（化學式累積時間＋認識元素累積時間）÷（兩者挑戰次數合計），越小越前面。例如兩種各玩一次，次數就是 2。
  - 化學式榜、認識元素榜各自用「該種類累積時間 ÷ 該種類次數」排序。
- 暱稱就是玩家的身分，同一個暱稱的成績會累積在一起；請提醒學生使用暱稱、不要用真實姓名。

**設定步驟（只需做一次）**
1. 用個人 Google 帳號（學校帳號若允許也可以）建立一個新的 Google 試算表，取名例如「化學式遊戲成績」。
2. 試算表上方選單 **擴充功能 → Apps Script**，把編輯器裡原有的程式全部刪掉，貼上 `GAS程式碼.gs` 的全部內容，按存檔。
3. 右上角 **部署 → 新增部署作業**，類型選 **網頁應用程式**：
   - 執行身分：**我**
   - 誰可以存取：**所有人**
   - 按「部署」，第一次會要求授權，依畫面同意（出現「這個應用程式未經驗證」時，點「進階 → 前往…」）。
4. 複製「網頁應用程式網址」（結尾是 `/exec`）。
5. 到 GitHub 編輯 `config.json`（點檔案 → 鉛筆圖示），改成：
   ```json
   { "gas": "貼上剛剛複製的網址" }
   ```
   Commit 後，重新整理遊戲網頁，就會出現暱稱視窗和「🏆 排行榜」按鈕。
6. 測試：在瀏覽器開啟「網址?action=board」，看到 `{"ok":true,...}` 就代表運作正常。

**管理榜單**
- 成績都在試算表的「成績」工作表，一次過關一列。要刪除不當暱稱，把那幾列刪掉；要清空榜單，保留第一列標題，刪除其餘列。
- 修改 Apps Script 程式後，要在 **部署 → 管理部署作業 → 編輯 → 版本：新版本** 才會生效。

**注意**
- 成績是學生自己的瀏覽器傳送的，懂程式的人可以偽造，適合班級競賽，不適合當正式成績。
- 「所有人」可存取的意思是：知道網址的人都能送出成績，請不要公開這個網址。
- 回應約 1～2 秒；榜單不會自動刷新，要按「重新整理」或重新開啟排行榜。
- 校園網路如果擋住 script.google.com，就無法上傳，請先在教室測試。

## 老師模式

點右上角淡淡的 ⚙，輸入密碼進入。可新增、編輯、刪除題目，設定出題範圍與每局題數（預設 10 題，其中 4 題進階），編輯元素介紹並上傳圖片。

- 讀到 GitHub 上的 Excel 時，在老師模式做的修改**只在這次開啟有效**（可用來預覽），重新整理就回到 GitHub 的版本。要讓大家都更新，請更新 GitHub 上的檔案。
- 出題範圍、題數等設定存在各台電腦自己的瀏覽器，不會同步。
- 讀不到 Excel 檔時（例如直接用檔案開啟、沒有網路），會自動改用程式內建的題庫與介紹，照常可以玩。
- 密碼寫在 `index.html` 的程式裡（搜尋 `pw').value==`），只用來避免學生誤觸，**不是安全機制**。公開的 repository 任何人都看得到，請先改成自己的密碼再發佈。

## 把下載的 index.html 也連到最新題庫

如果有人把 `index.html` 下載到電腦上用，預設只會用內建題庫。若要讓它也讀取 GitHub 上的最新檔案，請在 `index.html` 搜尋 `const BASE=''`，改成你的網址，例如：

`const BASE='https://<帳號>.github.io/<repository 名稱>/';`

（需要有網路。）

## 其他

- 如果 repository 設為 Public，題庫與圖片也會公開。
- 中文使用標楷體（DFKai-SB／BiauKai），英文數字使用 Arial；系統沒有這些字型時會自動換成其他字型。
- 音效由瀏覽器即時產生，需要先點過畫面才會發聲，右上角 🔊 可靜音。
